# Reference

Format rules for lookup documents. The purpose of this folder and where other content goes are in [../README.md](../README.md).

Create a reference page only when real content exists. Do not create stubs.

## What belongs

- Glossary and domain terminology.
- Configuration options: name, type, default, effect.
- API contracts and conventions the generated spec cannot express.
- Database schema notes that the schema and migrations do not express.

## Rules

- Link to generated API or schema documentation. Do not copy it.
- Keep entries factual and scannable: tables and definitions, not instructions or narrative.
- Each fact appears once. If a term is defined here, other documents link to it.
- Name files after the thing they describe, for example `glossary.md`, `configuration.md`.

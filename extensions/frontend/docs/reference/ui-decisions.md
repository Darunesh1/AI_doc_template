# Approved UI decisions

The locked register. An entry here has been approved by the person named in it. Agents and contributors must treat every entry as fixed.

## Rules

- Do not change a locked design, label, copy or behaviour listed here.
- To change one, get the approver's explicit approval, then record a new ADR in `docs/decisions/` that supersedes the old decision. Add a new row here and mark the old row superseded.
- Never delete a row. Mark it `superseded by <ID>`.
- If a requested change conflicts with a row, stop and ask instead of working around it.
- Record only decisions that were actually approved. Do not log guesses or proposals.
